# Clair Obscur Title

Lesson 18 from the [WebGPU & TSL](https://threejs-journey.com/) course by [Bruno Simon](https://bruno-simon.com/) — a title treatment with Three.js TSL.

**Live demo:** [askomarov.github.io/18-clair-obscur-title](https://askomarov.github.io/18-clair-obscur-title/)

## Setup

Download [Node.js](https://nodejs.org/en/download/).
Run the following commands:

```bash
# Install dependencies (only the first time)
pnpm install

# Run the local server
pnpm dev

# Build for production in the dist/ directory
pnpm build
```
